# KismoTech

Small, sensor-driven products, and the open C++ platform they're built on.

## Products

| | |
|---|---|
| **[PhantomFlow](https://kismotech.github.io/PhantomFlow.uk/)** | *Race your phantom.* Walk the line, ride it, and compare every run, sector by sector. For downhill mountain biking. |
| **[Pouncer](https://pouncer.uk)** | A cat collar module that detects the stalk-and-launch moment and sounds a single short cue, to give birds and small mammals a head start. |

## Open platform

| Repository | What it is | Licence |
|---|---|---|
| [KismoCore](https://github.com/KismoTech/KismoCore) | Portable C++23 data contracts for sensing devices, apps and engines: records, journal, time base, replay, decoders | MIT |
| [KismoEngine](https://github.com/KismoTech/KismoEngine) | Deterministic C++ runtime for apps, simulation and games | AGPL-3.0 or commercial |

Both build on the [Sub0](https://github.com/CraigHutchinson?tab=repositories&q=Sub0) C++ libraries,
and are proven in real projects such as [Crucible](https://github.com/CraigHutchinson/Crucible).
Code moves into the platform once a second project needs it, with its tests and history.

Commercial licensing for KismoEngine: open a *Commercial License Request* issue in its repository.
